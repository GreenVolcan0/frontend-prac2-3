Практическая работа №2: Сервер на Node.js + Express

Технологический стек: Node.js, Express.js

Что было реализовано:

    Инициализация сервера: Настроен базовый сервер на Express, слушающий определенный порт (например, 3000).

    Структура данных: Создан массив объектов для имитации базы данных товаров.

    Полный цикл CRUD:

        Create (POST /products): Добавление нового товара в список.

        Read (GET /products и /products/:id): Получение списка всех товаров и поиск конкретного товара по его уникальному идентификатору.

        Update (PATCH /products/:id): Частичное обновление данных существующего товара.

        Delete (DELETE /products/:id): Удаление товара из списка.

Практическая работа №1: CSS-препроцессоры

Технологический стек: SASS / LESS

Что было реализовано:
